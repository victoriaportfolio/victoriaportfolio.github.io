# Портфолио — Виктория

Чистый HTML/CSS/JS, без сборки. Стили — Tailwind через CDN (см. `<script src="https://cdn.tailwindcss.com">` в `index.html`).

## Структура

- `index.html` — разметка страницы
- `css/style.css` — точечные стили поверх Tailwind (аккордеон, плейсхолдер фото)
- `js/data.js` — **весь текстовый контент сайта**. Правьте здесь: имя, хиро-текст, скиллы, опыт по компаниям, проекты, ссылки на соцсети.
- `js/app.js` — рендер контента из `data.js` + логика аккордеона. Трогать не обязательно.
- `assets/images/` — сюда положите `photo.jpg` (ваш портрет). Пока файла нет — показывается плейсхолдер с буквой «В».
- `assets/logos/` — сюда логотипы компаний (SVG/PNG), когда будут. Как подключить — см. ниже.

## Типографика

Основной кегль — **Montserrat SemiBold 48px** (класс `.display-text`, определён в `index.html`
в блоке `<style type="text/tailwindcss">`). Он применён к hero, всем заголовкам секций,
блоку «обо мне» и заголовкам индустрий. На экранах уже 1024px уменьшается до 34px, на мобильных — до 26px.

Вспомогательный текст — 14px обычного начертания, цвет `#737373`.

## Структура блока «Опыт»

Двухуровневый аккордеон: индустрия (Fintech / E-commerce / Ed-tech) раскрывается в список
компаний, каждая компания раскрывается в «Что сделала» + «Ключевые достижения».

Достижения бывают двух видов:
- плоский список — поле `achievements` (так у МосБиржи, плюс подпись `achievementsSubtitle`);
- сгруппированный — поле `achievementGroups` с `label` для каждой группы (Сбер, Feymanlabs, БРЭ).

Цвет тегов задаётся полем `accent` у компании: `"green"` — фирменный зелёный Сбера,
по умолчанию синий.

## Как добавить реальное фото

Положите файл `photo.jpg` (квадратный, желательно от 400×400px) в `assets/images/`. Ничего в коде
менять не нужно — картинка подхватится сама, плейсхолдер исчезнет.

## Как добавить логотип компании вместо текстовой плашки

В `js/data.js` найдите массив `clientLogos` и замените:

```js
{ name: "MOEX GROUP", type: "text" }
```

на:

```js
{ name: "MOEX GROUP", type: "image", src: "assets/logos/moex.svg" }
```

## Форма связи

Сейчас кнопка «Написать на почту» — это просто `mailto:` ссылка (без сервера). Если позже
захотите настоящую форму с отправкой на почту без бэкенда — самый простой вариант это
[Formspree](https://formspree.io) (бесплатный тариф, просто меняете `action` у `<form>`) или
Telegram-бот через webhook. Оба варианта не требуют своего сервера.

## Языковые версии

Сайт двуязычный. Русский контент — `js/data.js`, английский — `js/data-en.js`.
Подписи интерфейса (заголовки секций, кнопки) — в объекте `UI_STRINGS` в конце `data-en.js`.

Переключатель в шапке меняет язык без перезагрузки и запоминает выбор в localStorage.
**Важно:** добавляя блок в `data.js`, добавьте его и в `data-en.js` — иначе в EN-версии его не будет.

## Деплой на GitHub Pages

Сайт статический, сборка не нужна — GitHub Pages подходит идеально и бесплатен.

1. Создайте на GitHub репозиторий. Имя определит адрес:
   - `username.github.io` → сайт будет на `https://username.github.io` (самый короткий вариант);
   - любое другое имя, например `portfolio` → `https://username.github.io/portfolio`.
2. Загрузите содержимое этой папки в репозиторий (можно просто перетащить файлы в веб-интерфейсе
   GitHub через «Add file → Upload files»).
3. В репозитории откройте **Settings → Pages**, в разделе «Build and deployment» выберите
   Source: «Deploy from a branch», ветку `main` и папку `/ (root)`. Сохраните.
4. Через 1–2 минуты сайт будет доступен по адресу выше.

### Свой домен

Если хотите адрес вида `victoria.design` вместо `github.io`: купите домен у любого регистратора,
затем в **Settings → Pages → Custom domain** впишите его, а у регистратора добавьте DNS-записи,
которые покажет GitHub. HTTPS включается там же галочкой «Enforce HTTPS».

Альтернативы с тем же результатом: Vercel, Netlify, Cloudflare Pages — все дают бесплатный
хостинг статики и подключение своего домена.
