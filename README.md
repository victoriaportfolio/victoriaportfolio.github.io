# Victoria — Portfolio

Static portfolio with a homepage and three case pages.

- Headings: local Montserrat; body text: local SF Pro.
- Homepage design: gradient background, two animated marquees, scroll reveal and parallax.
- Reduced-motion preferences disable the added animations.
- The first project uses a muted looping cover video.

After editing page renderers in `js/`, run `node scripts/prerender.mjs` to update static HTML and the text alternatives.

GitHub Pages publishes the `main` branch at the repository root. Keep `.nojekyll`.

Public URL: https://victoriaportfolio.github.io/
